How to write ionic formulae — cross-multiplication method
Step-by-step method:
1. Write the symbol and charge of each ion
2. "Cross the charges" — the number from one charge becomes the subscript of the other ion
3. Simplify if possible (e.g. if both numbers are 2, cancel to give 1:1)
4. If a polyatomic ion (like SO₄, NO₃, OH) needs a subscript, put it in brackets first

Example — Calcium chloride: Ca²⁺ and Cl⁻
→ cross the charges: Ca gets subscript 1 (from the 1), Cl gets subscript 2 (from the 2)
→ formula: CaCl₂

Example — Iron(III) oxide: Fe³⁺ and O²⁻
→ cross the charges: Fe gets subscript 2 (from the 2), O gets subscript 3 (from the 3)
→ formula: Fe₂O₃
Tip for typing: type subscript numbers as plain numbers — so Fe₂O₃ = Fe2O3, CaCl₂ = CaCl2, (NH₄)₂SO₄ = (NH4)2SO4
