The public landing page links only to resources for these current classes. Previous class material is retained in the repository's unpublished archive and excluded from GitHub Pages by `_config.yml`.

## 🚀 Quick Start

### 1. Add approved pupil-facing HTML files to the correct class folder
```
current/year-8/practical-enquiry/05-next-lesson.html
current/year-10/triple-biology-cells/03-next-lesson.html
```

### 2. Update index.html to link to your lesson

### 3. Push to GitHub
```bash
git add .
git commit -m "Add lesson"
git push
```

### 4. Enable GitHub Pages (first time only)
Settings → Pages → Deploy from branch → main → Save
