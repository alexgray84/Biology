Keep your own completed case judgement. Classify: read supplied facts; write a first judgement; ask for one question to locate a missing link; copy a complete answer. Use human learning work / bounded help / replaces thinking. Justify one choice.

3. Disclose and reflect

4. Different unaided retry

Close the reference and earlier work. A new long-term record has energy above needs and vitamin D below needs; other measured nutrients are adequate. Explain the category using both facts. Is starvation supported? State a possible D-deficiency effect in a child.
