Where is the image?

Use reflected rays to locate a plane-mirror image. Complete every construction and explanation in your exercise book.

Solid lines show real light paths. Dashed lines show where the reflected rays appear to come from.

Construction order

  1. Draw two incident rays from one point on the object to the mirror.
  2. At each contact point, draw a normal.
  3. Reflect each ray so i = r.
  4. Extend the reflected rays backwards using dashed lines.
  5. Mark the image where the dashed lines meet.

Copy the rule

In a plane mirror, the image is the same distance behind the mirror as the object is in front.

Task A · Complete the model

  1. Draw a vertical mirror line and place point P 4 cm in front.
  2. Draw two incident rays from P to different places on the mirror.
  3. Construct both reflected rays.
  4. Add dashed back extensions and label image P′.
  5. Measure object distance and image distance.

Task B · Change one feature

  1. Repeat with point Q 7 cm in front of the mirror.
  2. Keep the mirror orientation unchanged.
  3. Predict the image distance before constructing it.
  4. Write: “What stayed the same?” and “What changed?”

Use a ruler. Ray arrows must show the direction travelled by the light.

Teacher-marked diagram

  1. Construct the complete image using two rays.

Finish with this sentence stem

The image is virtual because the light rays do not actually __________; they only appear to __________.

Success criteria

  • Normals are perpendicular to the mirror.
  • At each reflection, angle i equals angle r.
  • Real ray paths are solid.
  • Back extensions are dashed.
  • Image and object distances are equal.
  • The explanation uses appear and virtual accurately.
