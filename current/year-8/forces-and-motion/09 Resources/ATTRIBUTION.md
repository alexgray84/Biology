# 09 Revision lesson and lab: attribution

- **Deck:** Arcadia lesson frame pinned from the 07 lesson resources (frame CSS/JS unchanged except `revision-frame.css` type scaling and one outcomes-screen string). All questions, models and diagrams are original.
- **Lab:** `09 Revision lab - seasons, weight, speed and graphs.html`, a single file with inline CSS/JS plus local `three.min.js` (three.js, MIT, `THREE-LICENSE.txt`). Montserrat is an optional Google Fonts link with system fallback.
- **Data:** the seasons model uses a 23.5° axis tilt and a circular orbit for teaching; planet g values (Moon 1.6, Mars 3.7, Jupiter 25 N/kg) are rounded teaching values; Planet X (Grade 8-9 only) is fictional.
- **Tarsia:** original engine and content; the format is the well-known Tarsia puzzle (tarsiamaker.co.uk). No third-party code or content.
- **Privacy:** nothing is stored or sent; no pupil names or class data.
