# 07 Revision lab: attribution

- **Format:** one HTML file (`07 Revision lab - cells, enzymes and osmosis.html`) with inline CSS and JavaScript, plus local `three.min.js` (three.js, MIT licence, see `THREE-LICENSE.txt`). No build step is needed by the pupil route. Montserrat is an optional Google Fonts link with system fallback.
- **Content:** every question, mark scheme, card and puzzle pair is original, written for Pearson Edexcel International GCSE Biology 4BI1 (Triple). No past-paper text, publisher illustrations or photographs are used.
- **Data:** the potato-osmosis results and the enzyme rate curves are illustrative teaching data, not measurements.
- **Tarsia:** the puzzle engine is original code. Tarsia is a well-known puzzle format (see tarsiamaker.co.uk); no code or content from that site is used.
- **Privacy:** nothing is stored or sent. No pupil names, class data or accounts. Confidence ratings and scores live only in the open browser tab.
