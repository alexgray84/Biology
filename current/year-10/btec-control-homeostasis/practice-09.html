Recover the allele rules

Record two answers using the stated classroom model.

  • R is dominant for a fictional seed pattern; r is recessive. Which phenotype does Rr show?
  • Which allele can an rr parent pass on?

What does a square represent?

Judge this claim in your record.

  • “Four boxes mean the family must have exactly four children, one of each type.”

Model a different cross

Watch the square build. Record why each parent contributes only one allele to a box.

  • Start with Rr × rr. The first parent can supply R or r; the second can supply only r. Put the gametes outside the grid.
  • Combine one allele from each parent: the top row is Rr and rr. Reject Rrr: an offspring receives only one allele from each parent at this gene.
  • Complete the lower row: Rr and rr. Half the boxes show each phenotype; this is a probability per offspring, not a promised family count.

Read relationships before alleles

Use the legend. Identify the parents and explain the child’s genotype.

  • In this fictional autosomal recessive condition, shaded means affected (aa). Unshaded means unaffected (AA or Aa).
  • Both unshaded parents have a shaded child. Each parent must have supplied a.
  • Both parents are therefore Aa. An unaffected sibling could be AA or Aa.

Complete the family reasoning

Record a cross for the two parents, then discuss the possible unaffected genotypes.

  • Use Aa × Aa for this practice pedigree. Label the gametes before filling the boxes.

What can an unaffected sibling be?

Choose an answer and justify it on your whiteboard.

    In the recessive practice pedigree, what genotype can an unaffected sibling have?

    1. Only AA.
    2. Only Aa.
    3. AA or Aa.

    Explain a new family model

    Work independently in your record. State the model before answering.

    • Use this new pedigree: shaded means a fictional dominant trait (D); unshaded means no trait (dd). Infer the genotype of each parent from their child.
    • Draw the parental cross and explain each phenotype’s probability.
    • A different person shows the dominant trait, with no family evidence. State all possible genotypes.
