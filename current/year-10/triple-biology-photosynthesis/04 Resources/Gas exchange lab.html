What this model assumes

  • Temperature stays constant, so each leaf's respiration rate stays constant. Temperature is not a variable in this model.
  • Every tube is sealed: no gas enters or leaves.
  • Every leaf is the same size and type; tubes start with the same indicator volume and colour.
  • The rates are simplified. Photosynthesis rises with light and slows as CO₂ is used up.
  • The indicator responds to CO₂ only. It is not an oxygen test and does not measure total photosynthesis. The model does not track oxygen.
  • CO₂ values and colours are an illustrative calibration, not real indicator data. Real dim tubes need not match this model.
