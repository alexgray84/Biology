Plan skeleton

  4. Control: …
  5. Measure … at the start and after …
  6. Repeat … and calculate …

Colour words and key words

Colour words

Every colour has a word. Read the word as well as the colour. The indicator shows CO₂ change only: it is not an O₂ test.

Key words

Plain-English meanings. Read-aloud and larger text are on the device page.

equilibrate
bubble air through the indicator until its colour stops changing, so every tube starts the same
systematic error
an error that shifts every reading the same way; repeats do not remove it
repeatable
similar results when you repeat the method
valid
the results answer the question: only the factor you changed affects them
quantitative
measured as a number
colorimeter
a machine that measures colour as a number
calibrate
check an instrument against a standard of known value, then correct it
control
a tube set up the same way, with no leaf
indicator
hydrogencarbonate indicator changes colour with CO₂; it is not an O₂ test
net
the overall result of photosynthesis and respiration together
