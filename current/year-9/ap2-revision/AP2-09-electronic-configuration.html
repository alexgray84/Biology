Electron shells and the Periodic Table

“Link Periodic Table position to electronic configuration.”

Big ideaElectrons fill shells in order: 2, then 8, then 8 (first 20 elements). The number of occupied shells = the period. The number of outer electrons = the group — and a full outer shell means a noble gas, Group 0.

AFilling the shells: sodium

  1. 1Electrons = atomic number (neutral atom): sodium 11.
  2. 2Fill in order: first shell 2, second 8, third 8, then the rest.
  3. 3Period = occupied shells. Group = outer electrons.

BThe first 20 elements

Down a group: same outer electrons, one more shell each row. Along a period: same number of shells, one more outer electron each step. Gold cells: sodium, magnesium, calcium.

Knowledge organiser · AP2 point 9 · part 2 of 3

CFull outer shells: the noble gases

A full outer shell puts an element in Group 0 (18). Helium has only 2 electrons, but its only shell is full, so it belongs with neon and argon — not in Group 2.

DKey words and what not to confuse them with

ShellAn energy level for electrons, drawn as a ring. First shell holds 2, then 8, then 8 (first 20 elements).≠ an electron’s fixed path
Electronic configurationThe number of electrons in each shell, inside out, e.g. sodium 2,8,1.≠ the atomic number
Outer electronsThe electrons in the last occupied shell.≠ the total number of electrons
PeriodA row of the Periodic Table. Period number = number of occupied shells.≠ group (a column)
GroupA column. Group number = outer electrons; Group 0 when the outer shell is full.≠ period (a row)
Noble gasGroup 0 (18): a full outer shell, e.g. helium 2, neon 2,8, argon 2,8,8.≠ Group 2 (helium has 2 electrons but a full shell)

FMisconception busters

  • ✗ “Chlorine, 2,8,7, is in period 7.”✓ The period is the number of occupied shells (3). The 7 is its outer electrons.
  • ✗ “Calcium has 20 electrons, so it is in Group 20.”✓ The group comes from the outer electrons only: 2,8,8,2 → Group 2.
  • ✗ “Helium has 2 electrons, so it belongs in Group 2.”✓ Helium’s only shell is full with 2, so it is a noble gas in Group 0 (18).
  • ✗ “Atoms in the same group have the same number of electrons.”✓ They share the same number of outer electrons. Neon has 10 electrons and argon 18.

GIn the UAE

Neon signs in Dubai: neon (2,8) glows in shop signs but does not react with the glass tube. Its outer shell is full, like every noble gas, which makes it very unreactive.

★ Going further: the 2,8,8 pattern works for the first 20 elements. After calcium, the third shell can hold more than 8 — you will meet this at GCSE.

Accept: “Same outer shell pattern” for the group mark if 2 outer electrons is stated. “Row” for period.

6Exam technique for this point

  • Count, then fillWrite the atomic number, then fill 2 → 8 → 8 → 2, crossing off as you go. Check the total matches.
  • Two rules, two numbersPeriod: count the rings. Group: count the dots on the last ring. Never use the same number for both.
  • Full shell? Group 0If the last shell is full (2 for helium, 8 for neon and argon), it is a noble gas — not Group 2 or Group 8.
  • Draw = check-list marksA 3-mark shell diagram is usually: right number of shells · right electrons in each · configuration written.
  • Quote the configurationIn an explain answer, write the configuration first — it is the evidence for both the period and the group.
