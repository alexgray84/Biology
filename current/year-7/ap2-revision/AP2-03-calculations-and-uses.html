Circuit calculations and electricity at home

“Complete simple electricity calculations and explain everyday uses of electricity.”

Big ideaEvery calculation uses four rules: series — current the same, voltages add up; parallel — branch currents add up, each branch gets the full voltage. Homes are wired in parallel, so every appliance gets the full voltage and has its own switch.

AThe calculation toolkit

Current (A)Voltage (V)
Seriesthe same everywhereV1 + V2 = supply
ParallelI1 + I2 = supplyeach branch = supply
  1. 1 Rule: branch currents add up to the supply current
  2. 2 Numbers: 0.80 = 0.30 + ? → 0.80 − 0.30
  3. 3 Answer: 0.50 A ✓ check: 0.30 + 0.50 = 0.80

BWhat the numbers mean

3 V = 3 joules transferred for every coulomb of charge

  • More resistance → less current on the same supply.
  • Add a lamp in series: more resistance, smaller current, all dimmer.
  • Add a branch in parallel: supply current rises; other branches unchanged.
  • Real meters don’t give perfect totals: 2.98 V + 2.98 V = 5.96 V against a measured 5.97 V supply still fits the rule.

★ Going further: resistance (Ω) = voltage (V) ÷ current (A)

Example: 4.0 V ÷ 0.50 A = 8.0 Ω

CElectricity at home

  • Parallel: each appliance gets the full voltage and its own switch, and stays on if another fails.
  • Switch in series with the thing it controls, on that branch.

DKey words and what not to confuse them with

ConductorA material that lets charge flow through it easily — metals such as copper.≠ insulator
InsulatorA material that does not let charge flow easily — plastic, rubber, glass.≠ conductor
Current (A)The rate of flow of charge, in amps. Splits and adds up at junctions.≠ voltage (V)
Potential difference (V)Energy transferred per coulomb of charge, in volts.≠ current (A)
Resistance (Ω)Opposition to the flow of charge, in ohms. More resistance → less current.≠ current
ApplianceA device that transfers energy from electricity: light, movement, heating, sound.≠ the supply

FMisconception busters

  • ✗ “The plastic carries the electricity.”✓ The copper core conducts. The plastic is an insulator that keeps the charge in the wire.
  • ✗ “One switch anywhere turns off just the fan.”✓ A switch only controls the path it is on. Put it in the fan’s own branch.
  • ✗ “Add every number you can see.”✓ Pick the rule first: currents add in parallel branches; voltages add in series.
  • ✗ “The heater uses up current to make heat.”✓ Current is the same in and out. Energy is transferred by heating.

GIn the UAE

A UAE summer evening: the AC, fridge and lights all run at once, each on its own parallel branch with the full mains voltage. Every extra appliance adds its own branch current, so the total current from the supply rises — which is why a home’s circuits have a limit.

★ Going further: resistance = voltage ÷ current. 4.0 V across a lamp with 0.50 A through it: R = 4.0 ÷ 0.50 = 8.0 Ω.

Mark scheme · 4 marks

  1. 1
    Each appliance is on its own branch — its own complete pathThe key parallel idea.
  2. 1
    So each can be switched on/off on its own, and the others stay on if one failsThe everyday benefit of separate paths.
  3. 1
    Each branch is across the same two supply points, so each appliance gets the full supply voltageThe voltage reason.

Accept: “Works at full power / full brightness” for mark 4. “If one breaks the rest still work” for mark 2.

Do not accept: “Parallel is safer” with no reason. “The voltage splits between them.”

★ Gold extension answer: Each branch current adds to the supply current, so the more appliances on, the bigger the current the supply and its wires must carry.

6Exam technique for this point

  • Rule before numbersWrite the rule in words first: “branch currents add up to the supply current”. It earns the method mark even if the arithmetic slips.
  • Show every step1.20 − 0.30 − 0.50 = 0.40 A. A bare answer that is wrong scores nothing; working can still score.
  • Right unit, every timeCurrent in A, voltage in V, resistance in Ω. Check you haven’t written V for a current.
  • Sense-checkA branch current must be smaller than the supply current. Series voltages must add up to the supply.
  • Uses = rule + resultTo explain an everyday use, give the circuit rule AND what it means for the person: “own branch, so it stays on when another fails”.
