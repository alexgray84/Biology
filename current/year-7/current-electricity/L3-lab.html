Investigation and record

Use One loop, two lamps followed by Keep the lights on. Keep 6 V and identical 10 Ω lamps throughout.

  1. Open Circuit Lab. Use Explore investigations to choose the named activity.
  2. Choose Start investigation once to load its starting circuit. Use Examples if the lesson asks for a different arrangement.
  3. Select the battery or a lamp to check its value. Tap one gold terminal, then another, to add a wire. Crossed wires do not join unless they share a terminal.
  4. Select a switch and use Open/Close switch. Record each result before changing the circuit.
  5. In Notebook, label each trial, write your explanation and use Save lab before leaving. Use current/voltage magnitudes when comparing readings.
  1. Record the One lamp example first. Remove one wire, add a second 10 Ω lamp and reconnect through both lamps in one loop. Use the Series circuit example as a scaffold if needed, then record both lamps.
  2. Remove one series lamp wire. Record both lamps’ behaviour. Undo the removal.
  3. Reconnect the two lamps as separate branches across the supply sides. Use the Parallel circuit example as a scaffold if needed. Trace both complete paths, then record supply current, both lamp currents and both powers.
  4. Remove the wire joining lamp 2 to lamp 1 on just one side. Leave lamp 1’s supply connections intact. Record the surviving branch and label this trial.

Compare the one-lamp, series and parallel readings.

Model answer & mark scheme

Typical 6 V / 10 Ω example magnitudes: one lamp ≈0.594 A and 3.526 W; series ≈0.298 A through each and 0.891 W each; parallel ≈0.588 A per branch, supply ≈1.175 A and ≈3.455 W per lamp. Small differences follow lead/source resistance.

Success criteria: Record actual readings with units; equal series currents; branch currents sum; series lamps dimmer.

What did each disconnection show?

Model answer & mark scheme

Series: both lamps off, because the single loop is broken. Parallel branch break: that lamp off, the other still on, because its path remains complete. The remaining current may rise slightly as source losses fall.

Success criteria: Both observations and path explanations, without claiming every parallel reading stays exactly fixed.

Meter connections

Ammeter: along the path

Replace a wire with the ammeter and its connections. Current must pass through it. The unit is A. Avoid a wire bypass or a direct meter connection across the battery.

Voltmeter: across two points

Keep the lamp circuit intact. Add one meter connection to each lamp terminal. The unit is V. If the sign is negative, the meter’s terminal direction is reversed; compare magnitudes.

The diagram is schematic. The simulator battery is one adjustable source; its setting is not a count of drawn cells.

Which meter replaces a wire in the current path, and which leaves that path intact?

Model answer & mark scheme

An ammeter is inserted in the current path. A voltmeter connects across the component while leaving its path intact.

Success criteria: Correctly distinguish both meters and their connections.

Complete the four-test matrix.

Model answer & mark scheme

Both switches closed: both lamps on. Only S1 closed: lamp 1 on and lamp 2 off. Only S2 closed: lamp 1 off and lamp 2 on. Both open: both lamps off and supply current 0 A.

Success criteria: Four correct states; real recorded values and units; no unintended bypass.

Recommend the design using the evidence.

Model answer & mark scheme

Use two parallel branches, each with its own series switch. The two mixed switch tests show either light stays on independently, meeting the shelter requirement.

Success criteria: Design choice, relevant test evidence and reason.

Success: opening either branch switch leaves the other branch available. Only the two mixed tests establish independent control.
