The four rules

Series — one path
  • Current is the same at every point.
  • Voltages across the components add up to the supply voltage.
  • Equal sharing of voltage only when the components are equal.
  • Break it anywhere and everything goes out.
Parallel — two or more paths
  • Branch currents add up to the supply current.
  • Each branch has the same (full) supply voltage.
  • Equal splitting of current only when the branches are equal.
  • Break one branch and the others stay on.

Notice the mirror: whatever adds up in series stays the same in parallel, and the other way round.

Things to stop saying

“The current is used up.” → The current is the same all the way round. Energy is transferred, not charge.
“The voltage splits at the junction.” → The current splits at a junction. Voltage is shared along a path.
“Series always shares equally.” → Only when the resistances are equal. A bigger resistance takes a bigger share.
“Put the voltmeter in the gap.” → That is the ammeter. A voltmeter goes on its own branch across the component.
